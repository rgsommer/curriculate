Edsby Cookie Sync

Keeps your Edsby session synced to the Behaviours app so parent notices keep posting via Edsby. Your cookie is sent only to the ingest URL below.

Just the domain you sign in to (no https://, no path).

Setup → Edsby → “Auto-push from your own browser script” → Generate token.

Advanced: ingest targets

Leave blank to use the default hosted endpoint. Every line gets the same push, so the cookie can reach more than one place. Add a line only if your school self-hosts the Behaviours backend, or to keep a Google Sheet's Edsby import working.

Google Sheet target: deploy the sheet's Apps Script as a Web app (Execute as: Me, Access: Anyone), then add its /exec URL with ?token=YOUR_TOKEN appended, matching the EDSBY_INGEST_TOKEN script property. The token goes in the URL because Apps Script cannot read custom request headers. Treat that URL as a password.

“One-time session” pushes your cookie into a short-lived slot the honour-roll run uses once — it isn’t stored on the server. Use it just before running the honour roll on curriculate.net/avgs.
