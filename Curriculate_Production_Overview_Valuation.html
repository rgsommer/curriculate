CURRICULATE

Production Overview & Development Valuation
Real-Time Multiplayer Classroom Platform
Prepared: April 2026 • Status: Production SaaS • Live at curriculate.net

1. Executive Summary

Curriculate is a production-grade, real-time multiplayer classroom platform that enables teachers to run interactive, station-based learning sessions with 55+ distinct task types. The platform includes four interconnected applications: a Node.js/Express backend with Socket.io for real-time communication, a React-based Student App for interactive task participation, a React-based Teacher App for session management and live monitoring, and a Next.js admin frontend for grading, analytics, and billing.

The platform integrates AI-powered task generation (OpenAI), payment processing (Stripe with tiered subscriptions), media storage (AWS S3), voice synthesis, and comprehensive session reporting with email delivery. It supports QR-code-based room entry, real-time scoring, multiplayer game mechanics, and detailed per-student analytics.

3.2 Platform Features

  • Real-time multiplayer sessions via WebSockets (Socket.io) with room codes and QR entry
  • Station-based rotation system with color-coded physical stations and QR scanning
  • AI-powered task set generation with streaming SSE delivery
  • AI scoring for open-ended responses with configurable rubrics
  • Paper Mode: camera-based submission for handwritten work with AI photo scoring
  • Live teacher dashboard with real-time student progress monitoring
  • Comprehensive session reports with per-student breakdowns and email delivery
  • Stripe billing integration with 5-tier plan system (Free through School Pro)
  • 30-day free trial with one-per-user enforcement
  • Voice cloning and text-to-speech for task narration
  • S3-based media upload with presigned URLs for photos, audio, and drawings
  • Shared taskset links for substitute teachers (guest JWT, 7-day expiry)
  • Jeopardy game mode with configurable contestant count and scoring
  • Demo mode with interactive task preview and SSE-streamed generation
