Built for the moment you're holding a stopwatch in one hand and a clipboard in the other.

Every feature was carved out of a real problem: lost result sheets, recalculated rankings, missing ribbons, and the announcer asking "Wait, who came third?"

⏱️

Multi-timer, every runner gets one

Each row has its own ▶/⏹ button and live clock. Tap "Start All" to launch the whole heat at once; tap each runner as they finish. Hundredths-of-a-second precision, no transcribing from a wrist watch.

📏

Distance & weight events too

One toggle picks the result type. Field events automatically rank highest-first; track events lowest-first. Best of 1, 3, or any number of attempts.

🧮

Two scoring modes, or both at once

Strict 1st / 2nd / 3rd placement points, AND/OR compete-against-the-standard. Turn on either or both in Settings — kids earn ribbons under whichever scheme they qualify for. Standards have gold/silver/bronze targets per event, age band, and gender.

🎺

School records with a horn blast

Set the school records once, or let the app capture them as kids set them. Every time a record falls, the horn blows, confetti drops, and the new record-holder's name shows on every device.

🏆

Top 3 — overall, by gender, by age band

End-of-day standings build themselves: top 3 across the whole school, top 3 girls and boys, top 3 in each age band. No manual tally, no spreadsheet sort.

🎀

Ribbon writer + 1-inch label sheet

One screen, every event, every place — sorted exactly the way you'll write the ribbons. Or print a sheet of 1"x1" Avery-style labels (70 per page) ready to peel and stick on the ribbons themselves.

📣

Announcer mode

The mic stand gets its own tab. As leaders submit results, completed categories queue up — title, place, name, time. Tap "Announced" and the next one slides in.

📋

Pre-populated event rules

Every event in the library has rules built in — start procedure, what counts as a foul, how the result is measured. Admin edits them in Settings; leaders see them right on the event screen so officiating stays consistent station to station.

👥

Multi-admin, with safe code change

Any number of admins can run the day — invite a colleague by email and they join in seconds. The school code can be rotated, but only with a confirmation code emailed to the original master admin.

✏️

Admin score corrections

Mistakes happen. Admins can edit a finalized result without reopening the event — the points and standings recalculate instantly across every screen.

📅

Start a new year, archive the old one

One click archives the current season. Last year's records, results, and ribbons are preserved — and restorable if you ever archived too soon by mistake.

🔄

Live across devices

Leaders submit on their tablet, the announcer queue updates automatically, the admin dashboard re-tallies in seconds. No manual refresh, no copying spreadsheets between phones.

📥

One Excel workbook, the whole field day

Download a pre-populated workbook with tabs for Roster, Events, Staff, Rules, Standards, Records, PBs, Houses, and Divisions. Fill it in from your school SIS, upload, done. Every entity in one file — no separate sheets to chase.

🎯

Heats, set by the PE teacher

Group strong-with-strong, weaker-with-weaker. Each event detail screen organizes competitors into heats — by CSV column, by drag-friendly inline editor, or both. Heats show on the announcer and on printed ribbons.

🎓

Run by grade, score by age

Schools that run heats by grade can still score by age. Toggle "Score Within → each age band" on the event, and the 5th-grade heat awards a separate 1st/2nd/3rd to the 10-year-olds and to the 11-year-olds. Standards stay accurate to each kid's age.

🌟

Personal bests, tracked & flagged

Upload each kid's prior PB once via CSV. When a field-day result beats their PB, a 🌟 toast fires and the ribbon shows a "PB" tag. PBs survive the year-end archive — next year picks up where this year left off.

🏠

Houses, with a winning crown

Set up your school's houses (Alpha, Beta, Gryffindor — whatever they're called) and a House Standings panel rolls every event's points up to the right house. Winning house gets a 👑 in real time.

🏃

Relay & team events, scored to houses

Mark an event as Team / Relay and the points flow only to the house standings — not to individual overall totals. Add teams with their roster and house in seconds; the announcer treats them like any other event.

📋

Library defaults, set once

Per-title defaults for type, attempts, and unit. Long Jump always pre-fills as Distance / Best of 3 / metres. Shot Put as Distance / Best of 3 / kg. New events spin up in seconds because the right defaults are already there.

📊

One-click Day Summary

End-of-day report on a single click: header, top 3 overall, top 3 by gender, top 3 by age band, house standings, current school records, and per-event top 4. Print it for the bulletin board, email it to parents — same content, both ways.

🏛️

Divisions, your way

Junior / Intermediate / Senior — or whatever your school calls them — defined by age range. Drives staff assignments, division-specific rules, and the leader Assignments view.

📜

Rules per division

Long Jump take-off line at 1m for Junior, standard for Intermediate. Shot put 2 kg for Junior, 3 kg for Intermediate. Set the base rules once, override per division, and leaders see the right rules for the kids in front of them.

🧑‍🏫

Staff per event & division

Mr. Smith leads Junior 50m. Mrs. Jones leads Intermediate Long Jump. Any role label works — Leader, Assistant, Scorer, Timekeeper. Assignments come straight from the workbook's Staff tab; the event detail shows who's running what.

📋

Leader Assignments view

Leaders sign in, pick their name from the staff dropdown, and land on a personal Assignments view: each event they're staff on, grouped by division, with status pips — green for done, amber for in-progress, gray for pending. No clutter, no scrolling past events that aren't theirs.

📡

Fast on bad Wi-Fi

The default page load is under 200 KB — no fonts, no analytics, no framework bloat. Heavy features (Excel import) lazy-load only when an admin actually clicks them. Built for a field next to a tree, not a fiber-lit office.

From sign-in to ribbons in under five minutes.

  1. 1

    Admin signs in & creates the school

    Enter your email, get a passkey on screen, set the school name, and pick a school code. Save it — that code is what your event leaders will use.

  2. 2

    Event leaders join with the code

    On their tablet or phone, leaders punch in the school code and their name. They land on a clean Events screen — ready to spin up a race.

  3. 3

    Pick the event, pick the category

    Choose from a built-in library (50m, Long Jump, Shot Put, Sack Race, and many more), or type a custom title. Set age, gender, and result type. Add competitors as they show up.

  4. 4

    Run the event, hit Submit

    Start, stop, type a distance, repeat. Best result auto-highlights, places appear live, points calculate themselves. When the heat is done, tap Submit & Complete.

  5. 5

    Admin announces & prints ribbons

    The Announcer tab queues every completed category. The Ribbons tab prints a clean, sorted list, ready for the marker pen. The Admin tab keeps a running points total per category.

Questions, answered.

How does multi-admin work?

The first admin signs up by email and gets a passkey. They name the school and pick a school code. Any other admin signs in with their own email + passkey, then joins by entering the school code — they're added as an admin instantly. Use the in-app "Invite Admin by Email" button to send the code to a colleague.

Can the school code be changed?

Yes, but only with confirmation. Any admin can request a code change; a 6-digit confirmation code is emailed to the original (master) admin. They share that code, the new code goes in, the change takes effect, and old code stops working.

Do event leaders need accounts?

No. Leaders sign in with the school code plus their own name — no emails, passwords, or app installs. Takes about 10 seconds.

What's the difference between placement scoring and standards scoring?

Placement awards 5/4/3/2/1 points for 1st through 4th plus participation. Standards compares each result against gold/silver/bronze targets you've set per event and age band — every kid who beats the bronze standard earns a ribbon at that level, regardless of how many other kids beat them. Many schools prefer standards for younger ages because effort is rewarded directly.

Where do the default standards come from?

The app seeds reasonable starting values for ~16 common events (sprints, distance runs, jumps, throws) across 5 default age bands and both genders. They're starting points only — adjust them in Settings to match your region or what your school uses.

What happens when someone breaks a school record?

The horn blows, a celebration banner pops up with the kid's name and result, and the new record is saved with the date and holder. The Admin tab shows the running list of records, with new ones flagged. Admins can also enter records manually (e.g. last year's bests) so the app knows what to compare against.

Can I print labels for the ribbons themselves?

Yes — the Ribbons tab has a "Print Label Sheet" button that emits 70 labels per page on a 1"x1" Avery-style stock (5418, 22806, 9099 and similar). Each label has the place, name, event, age/gender, and result. Peel and stick.

Does this need internet?

For multi-device live sync, yes — but only normal Wi-Fi. The client polls the Curriculate backend every few seconds. If Wi-Fi drops mid-event, the app keeps a local cache and you can still finish the day; sync resumes when the network comes back.

What about ties?

Two methods are supported: average tied positions (mathematically fair) or both get the higher place (simpler and more encouraging — common at elementary schools). Admin picks in Settings; rankings recalculate instantly.

Can admins fix a result after submission?

Yes — admins can edit a finalized event's results directly without reopening the event. Points totals and standings update everywhere automatically. (Leaders can also reopen their own events to edit before resubmitting.)

Can I customize event titles and age groups?

Yes. Settings lets the admin edit the event library, the list of individual age categories (used for tagging events), and the list of age bands (used for standards and overall standings). Each event in the library also has its own pre-populated rules text that admins can edit.

Best of 3, best of 5?

Set Attempts when creating the event (1–10). For field events like Long Jump or Shot Put, this is your best-of count — only the best counts toward placement.

How do houses work?

List your school's houses in Settings (Alpha, Beta, etc. — comma-separated). The CSV import accepts a House column, or you can assign per kid in the event detail. The Admin tab shows a House Standings panel summing up every event's points to the right house, with a 👑 on the leader. Team / relay events feed only the house standings — not individual totals — so your relay points go where they should.

How do personal bests (PBs) work?

Add a PersonalBest column to your CSV with each kid's prior best for the event you're recording. During the day, if their result beats their PB, a 🌟 toast fires and the ribbon shows a "PB" tag. PBs are stored at the school level so they carry across years (and survive the new-year archive).

What about relay and team events?

When creating an event, set Format to "Team / Relay." The "Add Competitor" button becomes "Add Team" — give the team a name, the optional members list, and a house. The team's place earns points that go straight to the House Standings, not to any individual's overall total. Records and standards apply per team.

Can I run multiple stopwatches at once?

Yes — every row in a timed event has its own ▶/⏹ button and live clock. Tap "Start All" to launch the whole heat at once; tap each runner's ⏹ as they cross the finish. Or run a one-runner-at-a-time event with just one row's timer. The horn celebration for record-breaks holds itself until any timer is stopped, so the announcement never interrupts a race.

Can I get a printable end-of-day summary?

Yes — Admin → Day Summary opens a single sheet with every cut: top 3 overall, by gender, by age band, by house, plus current school records and every event's top 4. Click Print and you have a bulletin-board-ready report.

How does the Excel workbook import work?

Admin → Download Workbook gives you an .xlsx file pre-populated with your school's current state across nine tabs: Roster, Events, Staff, Rules, Standards, Records, PBs, Houses, Divisions. Edit any tab in Excel or Google Sheets, then Admin → Import / Update from Excel to upload the changes. Each tab has its own importer; you can leave tabs you don't need blank. The Roster tab is the wide format: one row per kid, one column per event, cell values are Y or a heat label.

What about divisions — Junior, Intermediate, Senior?

Define them once in Settings (name + min/max age). They drive (1) the Staff tab — leaders/assistants per event × division, (2) division-specific rule overrides — different take-off lines, different equipment, (3) the leader Assignments view — leaders see only their assigned events grouped by division with status colors.

How do leaders find their events?

Leader signs in with the school code, picks their name from a dropdown that's auto-populated from the Staff tab, and lands on an Assignments view. Each event they're staff on is its own card; each division they're assigned to has a status pip — ✓ green when done, ⏱ amber when partly done, · gray when nothing's been started yet. They tap a specific event to score.

What about performance on outdoor / patchy Wi-Fi?

Initial page load is under 200 KB — no analytics, no fonts, no framework runtime. The Excel import library (~600 KB) only loads the moment an admin clicks the Excel button, then caches for the rest of the day. Live polling for the announcer queue is 6 seconds and skips a beat gracefully on bad networks. The app is built to keep working when the Wi-Fi is fighting back.

How does the roster CSV import work?

In the Admin tab, click Import Roster (CSV). Download the template, fill in one row per competitor-in-event with columns Event, Age, Gender, Name, Grade, DOB, Heat, ActualAge, then upload. The app shows a preview of every event it'll create or add to, plus any errors. Click Apply and it runs. DOB is optional — when present, the app computes each kid's age based on your school's cutoff date (default Dec 31; configurable in Settings).

Can we run heats by grade but score by age?

Yes — when creating an event, set Score Within to "Each age band separately." You can group all 5th graders into one event for the heat, but the placements split out by age — the 10-year-olds get their own 1st/2nd/3rd, the 11-year-olds get theirs. Standards-mode scoring continues to compare each kid against their own age band.

What about heat assignments for the PE teacher?

Each competitor has an optional Heat field — set it via the CSV column or click the gear icon next to a competitor in the event detail. The event screen visually groups competitors by heat. Strong-vs-strong, weaker-vs-weaker, however your PE teacher prefers.

How does the new-year archive work?

One click archives the current season. The app freezes the events, results, and announcer queue under whatever label you give it ("2025-26", "Spring 2026"), and your live screens reset to empty so you can start the new year. Archived seasons can be restored at any time.
