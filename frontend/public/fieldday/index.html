      Import Roster (CSV)
      
      
    
      
    
      
      
      
        Upload a CSV with one row per competitor-in-event. The app will create any missing events and add the competitors.
      
      
      
      
        CSV format & example
        
      Required columns: Event, Age, Gender, Name
      
        
      Optional columns: Grade, DOB, ActualAge, Heat
      
        
      
          Age = the event's competition tier (an 8-year-old running with the 9s gets Age=9).
          DOB = date of birth in YYYY-MM-DD; the app computes the kid's actual age as of the school's cutoff date (default Dec 31 — change in Settings).
          ActualAge = override if you don't want to use DOB or computed age.
          Heat = a label like "1", "A", or "Fast" — the event detail groups competitors by heat.
