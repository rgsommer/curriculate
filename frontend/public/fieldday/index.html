      Settings
      

    
      
      
      Scoring
      
      
      Turn on either or both. Each kid earns ribbons under whichever scheme they qualify for.
      
      
      
    
      

    
      
      
      Tie-breaking Method
      
      
      
    
      

    
      
      
      Invite Event Leaders
      
      
      One row per staff name from the Staff tab. Type each leader's email, click Send Invite — they get a single email with the school code, their PIN (if required), and step-by-step instructions. The PIN is freshly generated on each send.
      

      
      
        
      
      

      
      
        
      
      
      
      When off (default), any signed-in helper at any event station can drive the clocks. When on, only the leader assigned to a given event (or admin) can start a race or reset times. Stopping a runner's clock is always open to any helper, in both modes.
      

      
      
        
      
      
      
      Off by default — many schools prefer leaders focus on their own event and let admin announce overall winners. Turn on for transparency: leaders get a 📊 button on the Events screen that opens a read-only school-wide leaderboard, refreshed live.
      

      
      

      
      
        
        
        
      
      
    
      

    
      
      
      Divisions
      
      
      Optional. Many schools group ages into named divisions (Junior / Intermediate / Senior). Used for division-specific event rules and per-division staff assignments.
      
      
      
      
      
        
        
        
        
        
      
      
    
      

    
      
      
      Houses
      
      
      Optional. If your school competes by houses (Alpha / Beta / etc.), list them here. The Admin tab adds a House Standings panel and the CSV import accepts a House column.
      
      
      
    
      

    
      
      
      Age Categories & Bands
      
      
      Categories are individual ages used to tag events. Bands are ranges used for standards and overall standings.
      
      
      
      
      
      
      
      
      When competitors are imported with a DOB, age is computed as their age on this date of the current year. Default is Dec 31.
      
      
      
        
      
      
    
      

    
      
      
      Event Library & Defaults
      
      
      Each event's default type, number of attempts, and unit. New events created from a title pre-fill from these defaults.
      
      
      
      
      
        
        
        
      
      
      
    
      

    
      
      
      Event Rules
      
      
      Pre-populated rules shown to event leaders running each event. Edit any of them; leaders see what you save here.
      
      
      
      
      
        
      
      
    
      

    
      
      
      School Records
      
      
      Add a baseline record manually, or let the app capture them as competitors set them. The horn blows on every new record.
      
      
      
      
      
        
        
        
        
        
        
        
        
      
      
    
      

    
      
      
      Performance Standards
      
      
      Targets per event, age band, and gender. 1st-level (gold), 2nd-level (silver), 3rd-level (bronze). Anyone who beats the 3rd standard earns a ribbon. Numbers below are starting points — edit for your region.
      
      
      
        
        
      
      
      
      
    
      

    
      
      
      School Code & Admins
      
      
      The school code lets event leaders join. Share it with other admins so they can join too. The code can only be changed with confirmation from the master admin.

      Import / Update from Excel
      
      
    
      
    
      
      
      
        Upload an Excel/Google Sheets workbook with the structure shown below. Each tab maps to a different importer; tabs you don't need can be left blank or removed.
      
      
      
      
        Workbook tabs reference
        
      
          
      TabPurposeShape
      
          
            
      RosterKids and what events they're inOne row per kid; one column per event title; cell value = empty (not in), Y (in, no heat), or a heat label (in, in that heat).
      
            
      EventsPer-title defaultsTitle, Type, Attempts, Unit, Format, ScoreBy, Rules (base text).
      
            
      StaffLeaders / assistants per divisionOne row per event title; columns are Division Role (e.g. Junior Leader, Junior Assistant). Any role labels work.
      
            
      RulesDivision-specific rule overridesOne row per (event, division). Columns: Event, Division, Rules.
      
            
      StandardsPerformance targetsEvent, AgeBand, Gender, Gold, Silver, Bronze.
      
            
      RecordsSchool recordsEvent, Age, Gender, Holder, Result, DateSet.
      
            
      PBsPersonal bestsName, Event, Result.
      
            
      HousesHouse list (optional)One column "House" with one house per row.
      
            
      DivisionsDivision definitions (optional)Name, MinAge, MaxAge.
      
                
        
      
        
      Click Download Workbook on the Admin tab for a pre-populated starting file with your school's current state.

      Import Roster (CSV)
      
      
    
      
    
      
      
      
        Upload a CSV with one row per competitor-in-event. The app will create any missing events and add the competitors.
      
      
      
      
        CSV format — column groups & example
        
      
          
      GroupColumnRequired?Notes
      
          
            
      IdentityNameyesCompetitor or team name. Same kid across rows is merged automatically.
      
            
      EventyesEvent title — matches the library, or auto-creates with library defaults.
      
            
      Event slotAgeyesThe event's competition tier (an 8-year-old running with the 9s = Age=9).
      
            
      GenderyesGirls / Boys / Mixed
      
            
      Roster infoDOBoptionalYYYY-MM-DD. Auto-computes ActualAge using your cutoff (default Dec 31).
      
            
      GradeoptionalClass grade (1–12, K, etc.).
      
            
      HouseoptionalMust match a house from Settings, or it'll be flagged.
      
            
      ActualAgeoptionalFallback if no DOB.
      
            
      Race dayHeatoptionalHeat label (1, A, "Fast"); groups visually in event detail.
      
            
      PersonalBestoptionalPrior PB in the event's unit. Flagged if beaten on the day.
      
            
      NotesoptionalFree-text annotation, kept on the entry.
      
            
      Team onlyMembersoptionalSemicolon-separated for team / relay events. Use semicolons (commas conflict with the CSV).
      
                
        
      
        
      Roster info (DOB, Grade, House) only needs to be filled in once per kid — the importer merges by Name. Conflicting values flag a warning at preview.
